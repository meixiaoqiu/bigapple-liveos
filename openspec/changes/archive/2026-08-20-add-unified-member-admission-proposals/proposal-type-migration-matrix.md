# 提案类型迁移矩阵

| 流程 | 聚合根 | 当前策略 | 本变更结果 | 执行适配器 |
| --- | --- | --- | --- | --- |
| 守约者准入 | `ApprovalProposal` | 失败关闭 | 迁移到版本化选民策略 | 成员准入适配器调用角色任命服务 |
| 采购采纳 | `ApprovalProposal` | 固定审批槽 | 保持现状，后续单独迁移 | 既有采购适配器 |
| 采购付款 | `ApprovalProposal` | 固定财务审批槽 | 保持现状，后续单独迁移 | 既有采购付款边界 |
| 库存调整 | `ApprovalProposal` | 当前审批策略 | 保持现状，后续单独迁移 | 当前实现或明确不可执行 |
| 角色任命与卸任 | 无可运行提案 | 失败关闭 | 继续失败关闭 | 无 |
| 财务职责任命 | 无可运行提案 | 失败关闭 | 继续失败关闭 | 无 |
| 社区共议 | 无可运行提案 | 失败关闭 | 继续失败关闭 | 无 |
| 守约事务 | 无可运行提案 | 失败关闭 | 继续失败关闭 | 无 |
| 专业事务 | 无可运行提案 | 失败关闭 | 继续失败关闭 | 无 |
| 管理事务 | 无可运行提案 | 失败关闭 | 继续失败关闭 | 无 |
| 公开反馈转行动 | 无可运行提案 | 失败关闭 | 继续失败关闭 | 无 |
| 仿真自动决策 | 无可运行提案 | 失败关闭 | 继续失败关闭 | 无 |

适配器必须声明稳定类型代码、来源对象、幂等键、允许的策略、发起权限、执行权限、执行前置条件和领域动作。统一生命周期服务只能通过注册表获取适配器，不允许继续增加散落的提案类型执行分支。
