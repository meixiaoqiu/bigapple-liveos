## 2. 任务创建与发布体验

- [x] 2.1 将任务创建表单拆分为“保存草稿”和“锁定预算并发布”两个显式 intent；验证标准：保存草稿不产生锁定交易，零积分任务可直接发布。
- [x] 2.2 让创建并发布路径调用领域编排：余额充足时一次完成创建、锁定和发布，余额不足时保存草稿且不部分锁定；验证标准：页面消息准确说明最终任务状态和差额。
- [x] 2.3 将既有草稿的发布操作切换为自动补足预算缺口的组合服务；验证标准：无预算和部分预算草稿均只锁定缺口，足额预算草稿不重复锁定。
- [x] 2.4 在任务页展示预计奖励、发行池余额、已锁预算和预计补锁额，并在不足时提供积分预算入口；验证标准：展示仅作提示且服务端提交会重新校验最新余额。
