## 3. 议事者任期、维护者职责与专业资格

- [x] 3.1 为 `RoleAssignment` 增加本人主动申请的来源类型，并实现议事者自助申请服务：仅有效正式成员可申请、无需审核、立即生效、任期一周年、拒绝重叠任期且服务写明状态变化语义。
- [x] 3.2 实现议事者到期和再次申请规则，按统一当前时间查询使到期任期立即失效，不自动续任，也不复用到期任期。
- [x] 3.3 建立维护者角色、明确维护权限和 bootstrap 路径；维护者不得自动创建议事者任期、投票资格或正式审议资格。
- [x] 3.4 新增专业领域定义与成员专业资格权威模型、schema 迁移和服务，记录外部确认来源、确认人、状态与有效期；不得复用 `CredentialGrant` 作为权限来源，也不得实现面试或评估流程。
- [x] 3.5 增加服务与模型测试，覆盖非正式成员申请被拒绝、一年任期、闰年日期、到期不续任、重新申请、维护者无投票权、专业资格撤销或到期和用户停用。

## 4. 提案选民政策与投票授权
