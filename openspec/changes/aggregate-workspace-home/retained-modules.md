# Workspace 首页旧模块待确认清单

本次实施不删除下列任何模块。新事务区域上线后，使用者按本清单逐项确认是否保留、迁移到专页或删除。

| 旧模块 | 与“我的事务”的重叠 | 本次处理 |
| --- | --- | --- |
| 待处理事项 | 审批、执行、采购验收、付款和质疑待办与“需要我处理”重叠 | 完整保留并下移 |
| 成员核心状态统计 | 不属于事务；提供身份、积分、开放任务数和资源预警摘要 | 完整保留并下移 |
| 下一步动作 | 任务提交、等待验收和申诉等待等提示与事务下一动作重叠 | 已由使用者逐项确认删除；见 `remove-workspace-next-actions` |
| 个人任务历史 | 已结束任务与“最近结束”重叠 | 完整保留并下移 |
| 当前任务 | 已领取、进行中、待验收和争议任务与前两个事务分组重叠 | 完整保留并下移 |
| 可领取任务 | 不重叠；属于参与机会，不是个人事务 | 完整保留并下移 |
| 近期积分流水 | 不属于当前事务投影范围 | 完整保留并下移 |
| 资源预警 | 不属于个人事务，除非未来形成明确责任事项 | 完整保留并下移 |
| 相关事件 | 是成员相关历史信息，不等同于可操作事务 | 完整保留并下移 |
| 申诉状态与提交表单 | 进行中和已结束申诉与事务分组重叠；提交表单仍是原操作入口 | 完整保留并下移 |

任何一项后续调整都应单独确认，并验证相应操作入口已有替代位置后再实施。
