# Workspace 首页旧模块待确认清单

聚合初次实施不删除下列任何模块。新事务区域上线后，使用者按本清单逐项确认是否保留、迁移到专页或删除；已实施的后续独立 change 更新当前处理状态，并覆盖初次上线时的存在性基线。

| 旧模块 | 与“我的事务”的重叠 | 本次处理 |
| --- | --- | --- |
| 待处理事项 | 审批、执行、采购验收、付款和质疑待办与“需要我处理”重叠 | 完整保留并下移 |
| 成员核心状态统计 | 不属于事务；提供身份和积分摘要 | 已由使用者确认从 Workspace 首页删除；成员状态继续在顶部身份摘要展示，积分数据未删除，未来财务页面另行规划 |
| 下一步动作 | 任务提交、等待验收和申诉等待等提示与事务下一动作重叠 | 已由使用者逐项确认删除；见 `remove-workspace-next-actions` |
| 个人任务历史 | 已结束任务与“最近结束”重叠 | 已由使用者逐项确认，以任务详情替代；见 `replace-workspace-task-history` |
| 当前任务 | 已领取、进行中、待验收和争议任务与前两个事务分组重叠 | 已由使用者逐项确认迁入任务中心与详情；见 `move-workspace-tasks-to-task-center` |
| 可领取任务 | 不重叠；属于参与机会，不是个人事务 | 已由使用者逐项确认迁入任务中心与详情；见 `move-workspace-tasks-to-task-center` |
| 近期积分流水 | 不属于当前事务投影范围 | 已由使用者确认从 Workspace 首页删除；积分账本及积分功能保持不变，未来财务页面另行规划 |
| 资源预警 | 不属于个人事务，除非未来形成明确责任事项 | 已由使用者逐项确认迁入 `/workspace/inventory/`；见 `move-resource-warnings-to-inventory` |
| 相关事件 | 是成员相关历史信息，与事务和详情时间线重复 | 已由使用者逐项确认删除；见 `remove-workspace-related-events` |
| 旧申诉状态与提交表单 | 后续独立 change 已确认由事件详情反馈入口和“我的事务”反馈投影承接 | 已删除，不再属于保留模块 |

任何一项后续调整都应单独确认。纯只读摘要可在不删除权威数据和既有功能入口的前提下直接移除；会删除操作能力的模块仍应先确认替代入口。
